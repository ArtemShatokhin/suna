# Project Memory

The **project brain** for `kortix-YT-infotainment` — durable, team-shared notes this project keeps about
itself. It lives in git and is curated through change requests. Agents read this index first with the
`memory` tool and add entries as the channel learns.

What belongs here: audience learnings, hook/visual/packaging patterns backed by analytics, production
gotchas, decisions. Each learning cites its evidence (episode + numbers) and the skill/rubric change it
implies. The `post-mortem` skill writes most entries; the harness-reflector keeps them tidy.

- [production.md](production.md) — pipeline facts and gotchas learned while building it
- [packaging.md](packaging.md) — titles/thumbnails/descriptions: measure legibility at 120 px, keep copy no looser than the film, chapter fields live in the script
